# RSV-outcomes_Inf_SARS_CoV2

This project contains R code that has been utilized to elucidate the following research questions:
Among adults (≥18 years) with hospitalization episodes due to ARTIs,
1.	What was the proportion and seasonality of episodes with all-cause viral etiology across pandemic periods (pre-pandemic, pandemic, post-pandemic)?
2.	What was the distribution of major viral etiologies across these periods?
3.	Were there differences in clinical outcomes of RSV compared with SARS-CoV-2 and influenza among adults hospitalized with these infections across pandemic periods?

**Study setting:** Five acute care hospitals in Stockholm County, Sweden: Karolinska University Hospital, Danderyd Hospital, Södersjukhuset, Norrtälje Hospital, Södertälje Hospital. 
**Timeframe:**  January 1, 2017, to December 31, 2024
**Data sources:** Stockholm Regional Healthcare Data Warehouse (VAL), TakeCare® Intelligence database, Swedish Intensive Care Registry (SIR).

To run the analysis, execute the scripts in the `scripts/` directory in numerical order.
